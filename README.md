# Arstotzka Note Inspector

A Papers-Please-inspired note-taking app built with vanilla HTML/CSS/JS.

## Features

- Create, edit, duplicate, archive, reject, and restore notes.
- Text notes and checklist notes.
- Search, status filters, sorting, board/list view toggles.
- Pinning-ready sort behavior and priority classification.
- Approval/denial stamping workflow.
- LocalStorage persistence.
- Export/import note ledgers as JSON.
- Ambient CRT styling, alarm drill animation, and synthesized sound effects.
- Keyboard shortcuts:
  - `N` → new note
  - `Ctrl/Cmd + S` → save note

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
